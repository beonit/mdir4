## Manual checklist

- [ ] Start, Ctrl+Q quit, error and panic terminal restoration
- [ ] Drive root, UNC, long path, Korean/Unicode path
- [ ] Default associated application launch
- [ ] Trash and separately confirmed permanent delete
- [ ] Resize, Alt+Tab return and rapid repeated keys
- [ ] Built-in copy is English; Unicode filenames, paths and user labels remain unchanged
- [ ] 10,000-entry directory
- [ ] 1 GiB copy progress/cancel
- [ ] Classic Mdir reference comparison

Screenshots go under `docs/releases/assets/v1.0-rc/` and are linked from the matrix/checklist rather
than embedded as machine-specific absolute paths.
