## Local packaging preflight

2026-07-26 UTC에 macOS clean checkout과 Ubuntu 26.04 Lima VM에서 각각
`cargo build --release --locked`를 실행했다. Linux VM의 공유 workspace는 read-only이므로
동일 source commit의 `git archive`를 VM 임시 directory로 풀어 native build했다. ZIP에는 실행
파일, README, DEVELOPMENT, locked dependency license inventory만 포함되며 `unzip -t` 검증이
성공했다.
